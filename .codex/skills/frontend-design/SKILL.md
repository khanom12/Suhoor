# Frontend Design

Source methodology: https://github.com/anthropics/skills/tree/main/skills/frontend-design

Read `AGENTS.md`, `.agents/product-marketing.md`, and the finalized copy before reshaping presentation.

Treat the hero as the page thesis. Make typography, spacing, imagery, structure, and motion reinforce the product's actual subject: the Muslim morning and Fajr. Structure must encode meaning rather than decorate it. Spend visual boldness in one justified signature element and keep everything else disciplined.

Avoid generic AI landing-page defaults, gratuitous gradients, decorative cards, arbitrary numbering, excessive motion, and visual devices unrelated to the product. Preserve existing dawn assets when a task requires them.

Words are design material: keep copy plain, active, specific, and consistent with the action it enables. Design for mobile, keyboard access, readable contrast, reduced motion, localization/RTL, low light, and half-awake use.

Do not let visual novelty weaken trust, clarity, performance, or the calm/dignified character established by `AGENTS.md`.

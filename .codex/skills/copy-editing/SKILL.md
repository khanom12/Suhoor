# Copy Editing

Source methodology: https://github.com/coreyhaines31/marketingskills/tree/main/skills/copy-editing

Read `AGENTS.md` and `.agents/product-marketing.md` first. Preserve the strategic message unless evidence requires changing it.

Run seven sequential sweeps:
1. Clarity — understandable on first scan; remove jargon and ambiguity.
2. Voice and tone — calm, consistent, respectful, serious, human.
3. So what — connect every meaningful feature or statement to user value.
4. Prove it — remove, soften, or flag unsupported claims.
5. Specificity — make language concrete without inventing numbers or certainty.
6. Emotion — create resonance through truthful lived experience, never manipulation.
7. Zero risk — make next steps, limitations, privacy, and expectations clear.

Then perform an anti-AI pass: remove generic startup phrases, inflated adjectives, repetitive rhetorical structures, empty contrasts, overuse of em dashes, and copy that could belong to any wellness/productivity app.

For Fajr Now, never intensify emotion through shame about missed prayer, fear, spiritual status, or fabricated communal pressure. Credibility and user dignity beat conversion pressure.
